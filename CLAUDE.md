# Harness Engineering Capstone

## Project purpose
This repository contains the evidence and reflection for the Udacity
Harness Engineering capstone.

## Project structure
- evidence/system-1: Claims Intake Agent run artifacts and tests
- evidence/system-2: Retail Support Context Strategy artifacts
- evidence/system-3: Claude Code configuration and validator evidence
- evidence/system-4: Multi-Shift Quality Monitoring artifacts
- reflection-brief.md: Evidence-grounded project reflection

## Working guidelines
- Preserve original run artifacts and terminal logs.
- Base reflection answers on actual test results, traces, and generated data.
- Do not invent token counts, costs, outcomes, or test results.
- Keep secrets, API keys, and credentials out of version control.
- Keep each system's dependencies isolated in its own virtual environment.

## Verification
Run tests and scenarios from their respective solution directories.
Record the test output and generated artifacts in the corresponding
evidence folder.

## Submission
The final submission must include all four evidence folders and the
completed reflection brief at the root of the submission archive.
